# EmployeeHub — Single File Edition

Advanced employee management internship demo.

## Features
- 5,000 generated employee records
- Pagination and fast search/filtering
- Individual employee profiles
- Add employee on a separate in-app screen
- Attendance, leave and performance linked to employees
- CSV export
- Calendar/event interaction
- Responsive dark enterprise UI
- LocalStorage persistence

## Deployment
This version intentionally has **no css/**, **js/**, or **data/** folders.

Upload `index.html` directly to the root of the GitHub repository. `README.md` is optional documentation.

For real employee data, use a secure backend/database with authentication and authorization.
